# Mi rendimiento

App personal para registrar el rendimiento por bloques de 1,5 horas, analizar tus mejores horas y mantener el foco.

- `index.html`: la app completa.
- `manifest.webmanifest` y `sw.js`: permiten instalarla en el celular y usarla sin internet.
- `icons/`: íconos de la app.

Se instala desde el navegador del celular (Chrome en Android: menú, Instalar app).
